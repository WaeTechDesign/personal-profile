Topik 01

Jenis-Jenis Cloud Computing

Cloud Computing adalah teknologi yang memungkinkan pengguna mengakses sumber daya komputasi, seperti server, penyimpanan, jaringan, dan aplikasi melalui internet.

A. Berdasarkan Model Layanan (Service Model)

1. IaaS

Infrastructure as a Service menyediakan infrastruktur IT virtual, seperti server, penyimpanan, dan jaringan. Pengguna dapat mengelola sistem operasi serta aplikasi sesuai kebutuhan.

Contoh: Amazon EC2 dan Google Compute Engine.

2. PaaS

Platform as a Service menyediakan platform untuk mengembangkan dan menjalankan aplikasi tanpa harus mengelola infrastruktur server secara langsung.

Contoh: Google App Engine dan Heroku.

3. SaaS

Software as a Service menyediakan aplikasi siap pakai melalui internet tanpa pengguna perlu mengelola server dan pemeliharaan aplikasi.

Contoh: Gmail, Google Workspace, dan Microsoft 365.

B. Berdasarkan Model Penerapan (Deployment Model)

1. Public Cloud

Layanan cloud dari pihak ketiga yang digunakan banyak pelanggan melalui infrastruktur bersama.

Contoh: AWS dan Microsoft Azure.

2. Private Cloud

Infrastruktur cloud yang didedikasikan untuk satu organisasi sehingga pengelolaan dan pengaturan keamanannya dapat disesuaikan.

3. Hybrid Cloud

Kombinasi Public Cloud dan Private Cloud yang memungkinkan integrasi serta pemindahan data atau aplikasi di antara keduanya.

4. Community Cloud

Infrastruktur cloud yang digunakan bersama oleh beberapa organisasi dengan kebutuhan, kebijakan, atau kepentingan serupa, misalnya institusi pendidikan.

Topik 02

Kelemahan Layanan Cloud Computing

  1. Ketergantungan pada koneksi internet: koneksi tidak stabil dapat menghambat akses data atau aplikasi.
  2. Risiko keamanan dan privasi data: data berisiko bocor, dicuri, atau diakses tanpa izin jika keamanan tidak memadai.
  3. Vendor lock-in: pengguna dapat kesulitan berpindah penyedia karena perbedaan teknologi, format data, konfigurasi, dan biaya migrasi.
  4. Biaya dapat meningkat: biaya bisa bertambah seiring peningkatan penyimpanan, komputasi, dan lalu lintas data.
  5. Downtime: gangguan penyedia cloud dapat membuat layanan tidak tersedia sementara.
  6. Kontrol infrastruktur terbatas: pengguna tidak selalu memiliki kendali penuh atas server, sistem operasi, dan konfigurasi.
  7. Risiko kehilangan data: kesalahan konfigurasi, penghapusan tidak sengaja, atau serangan siber dapat menyebabkan data hilang.
  8. Kepatuhan dan lokasi data: organisasi perlu memperhatikan aturan perlindungan data dan lokasi penyimpanan informasi.
💡 Hal penting: Penggunaan cloud tetap memerlukan pengaturan keamanan yang ketat, kontrol hak akses, dan pencadangan (backup) data berkala.
Topik 03

Keuntungan dan Kekurangan SaaS pada Aplikasi Penjualan POS

SaaS (Software as a Service) adalah model penyediaan perangkat lunak melalui internet. Dalam aplikasi POS (Point of Sales), pengguna dapat mengelola transaksi penjualan menggunakan aplikasi yang disediakan sebagai layanan terpusat.

Referensi pertanyaan menyebut aplikasi Mocha sebagai contoh POS. Uraian berikut membahas keuntungan dan kekurangan aplikasi POS berbasis SaaS secara umum; rincian fitur khusus Mocha dapat disesuaikan dengan kebutuhan aplikasi.

✅ Keuntungan

  • Dapat diakses melalui internet dari perangkat yang didukung.
  • Tidak perlu membangun dan mengelola server sendiri.
  • Pembaruan aplikasi umumnya dikelola otomatis oleh penyedia layanan.
  • Data penjualan dapat dikelola secara terpusat dan real-time.
  • Membantu pemilik usaha memantau transaksi dan operasional dengan mudah.
  • Biaya awal infrastruktur jauh lebih rendah dibanding membangun sistem sendiri.

⚠️ Kekurangan

  • Bergantung pada koneksi internet jika aplikasi membutuhkan koneksi online.
  • Dapat menimbulkan biaya berlangganan berkala (subscription model).
  • Data usaha disimpan atau diproses oleh pihak ketiga (penyedia layanan).
  • Fitur dan kustomisasi mengikuti ketentuan serta batasan penyedia.
  • Gangguan layanan dari penyedia (server down) dapat menghambat transaksi.
  • Perlu memperhatikan keamanan akun pengguna, kontrol otorisasi, dan backup data.
Topik 04

Contoh Aplikasi SaaS Berdasarkan Bidang

1. Hotel Reservation

Aplikasi reservasi hotel berbasis SaaS membantu pengelola mengatur pemesanan dan ketersediaan kamar, data tamu, serta jadwal check-in/check-out secara terpadu.

Contoh layanan: Cloudbeds dan Little Hotelier.

2. Rumah Sakit

Sistem rumah sakit berbasis SaaS membantu pendaftaran pasien, jadwal dokter, rekam medis elektronik, administrasi, dan koordinasi alur pelayanan medis.

Contoh kategori: Cloud-based Hospital Management System (HMS) atau Electronic Medical Record (EMR).

3. Bidang Kuliner

Aplikasi SaaS untuk usaha kuliner membantu pencatatan pesanan kasir, manajemen inventaris/stok bahan, meja restoran, dan pelaporan keuangan berkala.

Contoh layanan: Toast dan Square for Restaurants.

* Contoh nama layanan di atas merupakan ilustrasi penerapan nyata SaaS di berbagai industri.

Topik 05

Web Server Hosting dan Publikasi Website Pribadi

Web hosting adalah layanan yang menyediakan tempat dan sumber daya server agar file website dapat disimpan serta diakses publik melalui internet. Web server menerima permintaan dari browser pengunjung lalu mengirimkan kembali file website (HTML, CSS, JS, dan media).

Tiga Contoh Layanan Hosting

Layanan Jenis Keterangan
GitHub Pages Static Website Hosting Menerbitkan website statis langsung dari repository GitHub (HTML, CSS, JS, dan aset media). Gratis dan sangat cocok untuk portofolio.
Netlify Web Hosting & Deployment Platform Mendukung publikasi website statis dengan otomatisasi build / CI-CD yang terhubung ke Git, custom domain, dan sertifikat SSL gratis.
Cloudflare Pages Static & Edge Hosting Platform Menyajikan aset statis dan web frontend melalui jaringan edge global Cloudflare dengan kecepatan akses tinggi dan perlindungan DDoS.

* Ketentuan paket gratis, batas kuota bandwidth, dan fitur masing-masing platform dapat berubah sewaktu-waktu. Selalu periksa dokumentasi resmi terbaru.

Rangkuman Akhir

Kesimpulan

  • Cloud Computing menyediakan akses sumber daya komputasi secara fleksibel melalui internet.
  • Model layanan cloud terdiri dari IaaS, PaaS, dan SaaS.
  • Model penerapan cloud terdiri dari Public, Private, Hybrid, dan Community Cloud.
  • Cloud menawarkan efisiensi tinggi, namun pengguna harus mengantisipasi risiko seperti dependensi internet, privasi data, vendor lock-in, dan potensi downtime.
  • SaaS memudahkan pengguna memakai aplikasi tanpa perlu memelihara server dan kode aplikasi secara mandiri.
  • Web hosting memungkinkan website dipublikasikan secara global; GitHub Pages, Netlify, dan Cloudflare Pages adalah opsi praktis dan populer untuk publikasi web.
📌 Inti Materi: Pahami perbedaan model layanan dan penerapan cloud, pertimbangkan kelebihan serta kekurangan sistem berbasis SaaS, lalu kuasai proses dasar mempublikasikan website ke platform web hosting.
